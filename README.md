# Gallery rooms

Walkable 3D rooms for the photography series of Volodymyr Demkiv. Open index.html.
Built with three.js r128. rooms.js is the shared engine, types.js holds the four room types.

Search: page titles, descriptions, social cards, structured data and the readable text for each room come from seo/rooms.json. After changing it or regenerating pages, run `python3 seo/apply.py`. It also rewrites sitemap.xml and robots.txt. Canonical domain: https://gallery.volodymyrdemkiv.com/
